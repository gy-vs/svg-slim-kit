Collapses links to JavaScript functions when the protocol is not lowercase,
as URL schemes are case-insensitive in browsers.

===

<svg xmlns="http://www.w3.org/2000/svg" xmlns:xlink="http://www.w3.org/1999/xlink" viewBox="0 0 100 100">
  <a href="JavaScript:alert('uwu')">
    <text y="10">uwu</text>
  </a>
  <a xlink:href=" JAVASCRIPT:alert('uwu')">
    <text y="20">uwu</text>
  </a>
</svg>

@@@

<svg xmlns="http://www.w3.org/2000/svg" xmlns:xlink="http://www.w3.org/1999/xlink" viewBox="0 0 100 100">
    <text y="10">uwu</text>
    <text y="20">uwu</text>
</svg>
